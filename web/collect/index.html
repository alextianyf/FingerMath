Digit Sample Collector

Research tool for Math Run (not part of the game). Write the number shown, then press Save (or Enter). Skip if you made a mistake. When done, Download the JSON and put it in web/collect/samples/.

Write: ?

Each sample stores the raw strokes (pad pixels), the pad size, the pointer type and, for single digits, the 28×28 image made by the game's own preprocessing (js/ai/processing.js). Samples are kept in this browser (localStorage) until you clear them.
